## 风险与注意事项

1. **时间轴运行时**：技能时序已由 Slate 迁移至自研 `SkillTimeline` + `SkillTimelinePlayer`（UI Toolkit 编辑器编辑）。SLATE 插件目录与旧 Slate 时间轴 prefab 已于 2026-08-22 删除（备份于 /tmp/unityDemo_slate_removal_backup）。
2. **xNode 共享图**：多个敌人共用一张状态图时，节点严禁保存运行时数据（放 `EnemyBlackboard`），否则会互相覆盖。
3. **ScriptableObject 只读**：运行期禁止修改配置资产，动态数值放实例/黑板。
4. **近战手感**：注意 `stoppingDistance` 与攻击范围滞后区间，避免贴脸/状态横跳。
5. **编辑器预览安全**：Clip 通过 `SkillClipContext.CanResolve`（`Application.isPlaying && !IsPreview`）统一区分预览与真实结算；编辑器预览只推进播放头与高亮活动 Clip，不执行伤害/生成。
6. **优先级**：时间不足时优先保证「完整状态闭环 + 调试可视化」，动画/美术/复杂武器可简化。
