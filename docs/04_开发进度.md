## 风险与注意事项

1. **Slate 版本兼容**：项目内置 Slate v2.2.3（ParadoxNotion）。若 API 与最新版不同，改动集中在 `SlateSkillPlayer` 适配层。
2. **xNode 共享图**：多个敌人共用一张状态图时，节点严禁保存运行时数据（放 `EnemyBlackboard`），否则会互相覆盖。
3. **ScriptableObject 只读**：运行期禁止修改配置资产，动态数值放实例/黑板。
4. **近战手感**：注意 `stoppingDistance` 与攻击范围滞后区间，避免贴脸/状态横跳。
5. **编辑器预览安全**：自定义 Slate Clip 必须用 `Application.isPlaying` 区分预览与真实结算。
6. **优先级**：时间不足时优先保证「完整状态闭环 + 调试可视化」，动画/美术/复杂武器可简化。
