# 02 子任务拆分

按模块拆分，每个子任务包含：**编号 / 说明 / 依赖 / 验收标准**。
任务编号规则：`阶段-模块-序号`（阶段见 [04_开发进度.md](./04_开发进度.md)）。

---

## M0 工程准备与资源导入

| 编号 | 子任务 | 依赖 | 验收标准 |
|---|---|---|---|
| M0-1 | 导入并验证 xNode（已存在于 `Assets/Script/xNode-master`，确认可编译、可创建 NodeGraph） | 无 | 编辑器可创建 xNode 图资源，控制台无编译错误 |
| M0-2 | 导入 Slate Cinematic Sequencer v2.2.3（`.unitypackage`）——2026-08-22 已删除并迁移至 `SkillTimeline` | M0-1 | `using Slate;` 可编译；`Cutscene` 类型可引用；编辑器可创建 Cutscene |
| M0-3 | 创建 `Assets/Game` 目录骨架（AI/Characters/Combat/Camera/UI/Configs/Prefabs/Scenes/Tests） | 无 | 目录结构与设计文档一致 |
| M0-4 | 配置包清单/程序集引用（xNode；Slate 引用已于 2026-08-22 移除） | M0-1, M0-2 | 运行时/编辑器程序集编译通过 |

## M3 敌人 AI（xNode 状态机）

| 编号 | 子任务 | 依赖 | 验收标准 |
|---|---|---|---|
| M3-1 | `EnemyContext` + `EnemyBlackboard`（运行时数据，节点不存运行时状态） | M0-3 | 黑板保存 StateTime/RepathTimer/PatrolPointIndex/LastKnownPosition 等 |
| M3-2 | `EnemyStateGraph : NodeGraph` + 节点基类 `EnemyStateNode`（Enter/Tick/Exit/EvaluateTransition/GetConnectedNode） | M0-1 | 节点生命周期方法可用 |
| M3-3 | `EnemyEntryNode` / `EnemyAnyStateNode` | M3-2 | 入口唯一；AnyState 可做全局死亡转换 |
| M3-4 | `IdleStateNode` / `PatrolStateNode`（巡逻点移动） | M3-1, M3-3 | Idle 随机停留后进入 Patrol；到达巡逻点回 Idle |
| M3-5 | `EnemyPerception`：距离 + 视野角 + Raycast 遮挡 + 警觉值 | M2-2 | 背后不被立即发现；障碍阻挡视线；警觉值升降正确 |
| M3-6 | `EnemyMotor`：NavMeshAgent 移动/转向/停止距离 | M3-4 | 追击/巡逻移动正确，停止距离适配武器射程 |
| M3-7 | `ChaseStateNode`：重寻路 + 最后发现位置记录 | M3-5, M3-6 | 按间隔重寻路；进入武器范围转 Attack；丢失目标转 Investigate |
| M3-8 | `AttackStateNode`：通过 CharacterCombat 攻击，近战/远程自适应 | M2-3, M3-7 | 近战近身挥砍、远程远程射击；超范围转 Chase；丢失转 Investigate |
| M3-9 | `InvestigateStateNode` / `ReturnStateNode` / `DeadStateNode` | M3-7, M3-8 | 搜索后转 Return；返回后回 Patrol；死亡转 Dead 并停用行为 |
| M3-10 | `EnemyStateMachineRunner`（全局转换优先 + 当前状态转换 + Tick） | M3-2 ~ M3-9 | 状态切换顺序正确；多个敌人共用一张图互不干扰 |
| M3-11 | `EnemyActor`：按依赖顺序统一初始化（生命→移动→感知→武器→状态机） | M3-1 ~ M3-10 | 初始化顺序正确，无空引用 |
| M3-12 | `EnemyGraphValidator`（编辑器校验） | M3-10 | 能检测缺 Entry、孤立状态、端口未连接等错误 |

## 子任务依赖关系（关键路径）

```text
M0 资源导入
 └─► M1 玩家/相机
 └─► M2 战斗系统
      ├─► M3 敌人AI（依赖 M2）
      │     └─► M4 配置化（依赖 M3）
      └─► M5 技能时间轴（依赖 M2 + M4，原 Slate 已迁移删除）
           └─► M6 表现/交付（依赖 M5）
```

**建议并行：** M1（玩家/相机）与 M2（战斗系统）可并行；M2 完成后 M3、M4 可并行推进。
